# NeoStorage — файловый менеджер

Современный веб-интерфейс для управления файлами и папками прямо из браузера. Приложение построено на **Node.js + Express** и оснащено стильным фронтендом без сторонних фреймворков.

## Возможности
- Просмотр файловой структуры с «хлебными крошками» и быстрым переходом между папками.
- Создание новых файлов и папок, переименование и удаление объектов.
- Редактирование текстовых файлов прямо в браузере с поддержкой `Ctrl + S`.
- Скачивание файлов и архивирование выбранных элементов в ZIP.
- Формирование архивов для произвольного набора элементов одним кликом.
- Защита от выхода за пределы рабочей директории.
- Встроенный веб-терминал с несколькими сессиями, живым выводом и восстановлением истории после перезагрузки страницы.

## Локальный запуск
```bash
npm install
npm start
```
После запуска файловый менеджер доступен по адресу [http://localhost:5000](http://localhost:5000), а терминальный интерфейс — по адресу [http://localhost:4000](http://localhost:4000).
Если платформа пробрасывает только один порт и переменные `PORT` и `TERMINAL_PORT` совпадают, веб-терминал автоматически обслуживается по пути `/terminal` на основном порту (WebSocket — `/terminal/ws`).

### Проверка терминального интерфейса
Для автоматической проверки работы веб-консоли выполните:

```bash
npm run check:terminal
```

Скрипт разворачивает сервер на временных портах, создает терминальную сессию, подключается к ней через WebSocket, выполняет команду `echo` и убеждается, что история корректно восстанавливается через REST API.

### Переменные окружения
| Имя | Значение по умолчанию | Описание |
| --- | --- | --- |
| `PORT` | `5000` | Порт HTTP-сервера |
| `TERMINAL_PORT` | `4000` | Порт веб-консоли (при совпадении с `PORT` используется путь `/terminal`) |
| `FILE_MANAGER_ROOT` | `<корень проекта>/storage` | Базовая директория для работы файлового менеджера |

## Запуск в Docker
```bash
docker build -t neostorage .
docker run -p 5000:5000 -p 4000:4000 -v $(pwd)/storage:/app/storage neostorage
```

## Структура проекта
```
├── src/server.js        # Express-сервер, REST API и WebSocket-шлюз терминала
├── public/              # Статические ресурсы файлового менеджера

├── Dockerfile           # Контейнеризация приложения
├── .dockerignore
└── .gitignore
```
